# Документация Saturn IDE

Начните с [DSL и роли TypeScript](dsl.md): первый проект, сигналы и оборудование, проверка типов, протоколы, расширения и граница между исходником и runtime. Этот же файл доступен в IDE: раздел документации → **DSL · TypeScript**.

[Архитектура](architecture.md) описывает владельцев модулей и жизненный цикл модели. [Матрица возможностей](capabilities.md) фиксирует реализованное и незавершённое. [Проверки](verification.md) описывают область верификации и её ограничения.

[Roadmap Saturn](../ROADMAP.md) фиксирует планы Mobile / Cloud / Agent: совместную работу участников, разработку и монтаж с телефона, пространственный контекст, проектирование по документам и интеграцию существующих камер. Этапы имеют зависимости и критерии приёмки; планы не подменяют реализованные возможности или обязательства переноса.

[Протоколы](protocols.md), [развёртывание runtime](runtime-deployment.md), [инфраструктура](infrastructure.md) и [импорт существующих проектов](importers.md) раскрывают отдельные рабочие сценарии.

Документация конкретного инженерного объекта генерируется из его `Project`. Руководство по DSL объясняет язык и не включается в состав этой объектной документации.
