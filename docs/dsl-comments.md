# Неактивный исходник: `//` и пол редактора

`//` в TypeScript остаётся обычным комментарием. Saturn не меняет семантику JavaScript: закомментированного кода нет в активной модели и runtime. Общий authoring читает распознаваемые объявления и ссылки в Project-массивах как **неактивные сущности редактора**. Это производная информация из текста, не скрытый enabled-флаг и не вторая инженерная БД.

```ts
const start = cable('start', {
  from: controller.ports.DO1,
  to: pump.ports.run,
  signal: pump.run,
});
export default project({
  id: 'station', label: 'Станция',
  equipment: [controller, pump], pipes: [], alarms: [],
  cables: [
    // start,
  ],
});
```

Это фрагмент существующего проекта, а не самостоятельный модуль. Пока ссылка отключена, кабель остаётся в редакторе с концами на полу. Включение через сцену или исходник редактирует ту же TS-программу. Удаление определения и ссылок действительно удаляет сущность. Все устройства можно держать в одном файле или в обычных модулях.

Обратное редактирование использует общие `Documents`, `LayoutEditing`, `SourceEditing` и TypeScript AST. Перемещение показывает transient preview; завершение жеста записывает source-изменение с проверкой версии. Escape/capture loss отменяют жест. Undo работает в общем редакторе. Ошибочный код не применяется к физическому объекту.

Неактивный кабель — не то же самое, что активный кабель со свободным концом. Последний выражается явно:

```ts
// В том же модуле импортирован free из используемого пакета Saturn.
const loose = cable('loose', {
  from: free(controller.ports.DO1, { x: 200, y: 400, z: 0 }),
  to: free(pump.ports.run, { x: 500, y: 400, z: 0 }),
  signal: pump.run,
});
```

Каждый конец трубы или кабеля независим: attached Terminal либо Free с authored position и профилем совместимости. Свободный конец не занимает прежний порт. Нельзя считать путь между свободными концами работающим физическим соединением.

Представление `AuthoringFrame.scene` не публикуется и не устанавливается в runtime. Проверенный `AuthoringFrame.project` исключает неактивные сущности. Схема артефакта остаётся `saturn.build@2`. Сохранённые концы `unplugged`/`looseEnd` при разборе становятся `free()` без удаления кабеля.

Общий механизм распознаёт обратимые объявления, ссылки, алиасы и модули; не обещает обратимость произвольного вычисления или побочного эффекта TS. Отключение оборудования, на которое ссылается активная программа, может потребовать явного отключения потребителей. Редактор показывает ошибку, а не молча удаляет зависимости.

SaaS-учебник является host этих же механизмов. Его текст и цели отдельны, документы, типы, сцены, операции и семантика комментариев — общие с IDE.
